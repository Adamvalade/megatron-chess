    About Megatron

    Megatron is a chess engine built from scratch in C++, featuring custom move generation, position evaluation, and optimized game-tree search.

    Its search algorithm combines alpha-beta pruning, quiescence search, and intelligent move ordering to evaluate chess positions efficiently. Zobrist hashing and transposition tables further improve performance by caching previously searched positions.

    Built with support for the Universal Chess Interface (UCI), Megatron can run independently in compatible chess applications or power this interactive web experience.

    Tech Stack
    C++, JavaScript, Node.js
    Key Algorithms
    Negamax, Alpha-Beta Pruning, Quiescence Search, Zobrist Hashing, Transposition Tables
